# Persoonlijke Ontwikkelomgeving – demo

Klikbare demo van de Persoonlijke Ontwikkelomgeving (Scrumteam Yelesion, ITIG).
Alle gegevens zijn voorbeeldgegevens. Opslaan werkt niet in deze demo; de echte versie is gebouwd in Laravel (PHP/MySQL).

Open `index.html` en klik op **Inloggen** (de gegevens zijn al ingevuld).
